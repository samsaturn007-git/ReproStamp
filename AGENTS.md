Read [README.md](README.md), [the product plan](docs/PRODUCT_PLAN.md), [implementation status](docs/IMPLEMENTATION_STATUS.md), and the requested PRD before making changes. Implement the requested PRD and record the commands, observed results, and any open exit-gate checks in [implementation status](docs/IMPLEMENTATION_STATUS.md). Verify each exit gate before advancing to a dependent PRD.

Keep the owner-managed browser tests and profiles outside the application tree. Run approved workloads with the runner boundary in the product plan and keep execution state, assertion outcomes, and verification verdicts distinct.
